## Questões Resolvidas

1. **Validador de Senhas Fortes**
   - O programa solicita que o usuário insira uma senha e verifica se atende aos critérios de segurança: mínimo de 8 caracteres, ao menos uma letra maiúscula, um número e um caractere especial.

2. **Tabuada Completa com Laço**
   - O usuário informa um número e o programa imprime a tabuada completa desse número de 1 a 10, utilizando um loop `for`.

3. **Cálculo de Fatorial com While**
   - O usuário digita um número inteiro positivo e o programa calcula o fatorial desse número usando um loop `while`.

4. **Conversor de Temperaturas com Menu**
   - Um menu interativo permite a conversão entre Celsius e Fahrenheit utilizando `switch` e `while` para manter o menu ativo até o usuário decidir sair.

5. **Verificador de Palíndromos**
   - O usuário digita uma palavra ou frase, e o programa verifica se é um palíndromo, desconsiderando espaços e acentos.

6. **Cadastro Simples de Produtos**
   - Implementação de uma classe `Produto` com propriedades de `Nome`, `Preço` e `Quantidade`. O usuário cadastra três produtos e o programa exibe todos com o valor total em estoque (`Preço * Quantidade`).

7. **Soma de Números Pares de um Array**
   - O usuário insere 10 números em um array, e o programa calcula a soma apenas dos números pares.

8. **Cálculo de IMC com Classificação**
   - O programa solicita peso e altura, calcula o Índice de Massa Corporal (IMC) e exibe a classificação correspondente.

9. **Jogo da Adivinhação**
   - O programa gera um número aleatório entre 1 e 100. O usuário tenta adivinhar e recebe dicas se o número é maior ou menor, contando o número de tentativas.

10. **Lista de Tarefas (To-Do List)**
   - O usuário pode adicionar tarefas a uma lista. No final, todas as tarefas inseridas são exibidas, com uma opção para marcar como concluídas.

---
Este repositório contém a implementação dos exercícios acima, visando aprimorar habilidades de programação e lógica computacional.
